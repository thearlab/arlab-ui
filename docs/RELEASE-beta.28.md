# ARLAB UI v2.0.0-beta.28

This release closes the remaining shared contracts raised by the internal dashboard: native-link `TextAction`, relative `Timestamp`, aligned `LinkTile` rows, adjustable `WorkspaceGrid` supporting width and `EditorLayout` inspector width, quiet `DayTimeline` days, flush `TabStrip`, cross-document `PreviewFrame` height messages, and per-route `ShellPage` scroll ownership.

The Kanban horizontal swipe and visible-height fixes from the earlier request are included. Existing defaults remain compatible; new layout options are opt-in.

See [route and component contracts](ROUTE-AND-COMPONENT-GAPS.md) for exact usage and iframe origin requirements. The showcase includes live examples of the link action, aligned tiles, quiet timeline and adjustable workspace column.

Install: `git+https://github.com/thearlab/arlab-ui.git#v2.0.0-beta.28`.
