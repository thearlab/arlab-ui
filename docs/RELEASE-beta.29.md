# ARLAB UI v2.0.0-beta.29

KanbanBoard column headers now have a full-width 1px bottom divider. The colored top accent is 2px instead of 3px. Both rules come from the shared component, including on read-only boards and in dark mode.

Right-side Sheets now have square edges. This applies to shared record, detail, and filter sheets while centered Dialogs retain their usual panel corners.

The Ongoing dashboard uses the shared board in read-only mode with its own project cards. The showcase demonstrates editable movement and sample cards by default, which explains the remaining content and control differences. Consumers can upgrade by pinning `v2.0.0-beta.29`; no API change is required.
