# Contour beta.6

Includes the beta.5 table improvements: ascending/descending header arrows, custom table/column headers, header action slots, custom cells and sort accessors, and the input-style focus border for rows-per-page selects.

Fixes the scrollable table header as one pinned layer inside its own viewport. Separate table borders and an opaque header background keep scrolling rows beneath the headings and preserve the divider. Pagination remains outside the table scroll region.
