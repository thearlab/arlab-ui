# Contour V2 beta.20

A small shared-control patch on the current Contour foundation.

- TagInput now uses compact neutral 28px chips with 24px embedded remove actions and 12px labels. Long names truncate with a tooltip inside wrapping tags. Disabled inputs keep their non-removable state. General public buttons retain their existing standardized sizing.
- TimePicker now has two equal 64px entries for two-digit hours and minutes, with no inherited 150px dropdown minimum. Date/time values, min/max availability and keyboard selection remain unchanged.
- Dropdown options use only the selected background and aria-selected; the selected checkmark is removed.

The light/dark Contour palette, Manrope and IBM Plex Mono remain unchanged. Platinum, Outfit and expanded font proposals remain development-only pending user approval.
