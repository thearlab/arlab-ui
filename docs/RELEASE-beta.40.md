# ARLAB UI 2.0.0-beta.40

The shared recessed pressed finish now applies only to the public Button and IconButton primitives, including their link forms and actual pressed toggles. Disabled, aria-disabled and busy controls are excluded.

Removed beta.39's generic button/role selector and added transient navigation glyph activation. Tabs, filter pills, dropdown options/triggers, rows, cards, text actions, scroll thumbs and navigation keep their existing own states. Earlier approved department/navigation selection styling remains.

No colors, contrast, typography, dimensions, gradients, glass rims or other foundation effects change. No API is removed. Consumers must upgrade their immutable package pin and rebuild.
