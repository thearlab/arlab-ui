# ARLAB UI 2.0.0-beta.37

SearchField uses a compact 12px clear glyph within a 28px action area that reaches the input's right edge. It no longer nests a full-size raised button inside the input or reserves extra right padding when the action is present. The shared input well, discreet focus styling, disabled state and clear-and-refocus behavior remain. Other IconButtons keep their normal sizing.

The icon gallery now uses the same SearchField rather than its own clear control.
